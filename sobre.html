Sobre este projeto

QUEM ESTÁ POR TRÁS?

Uma ideia feita para aprender em conjunto

Sou a Carla Nave. Este é um projeto de demonstração para aprender a planejar, construir e melhorar um site com a ajuda de IA.

COMO USAR ESTE SITE

Leiam, conversem, experimentem

Escolham uma situação. Leiam em conjunto, contem experiências e pensem num gesto que possam experimentar. Não precisam de seguir uma ordem.

COMO FOI FEITO

Planeado com cuidado

O planeamento e a revisão são da autora. A IA ajudou na construção do site. Os exemplos são situações ilustrativas criadas para este projeto.

PROJETO ACADÉMICO

Design de Interação

Este projeto foi desenvolvido como exemplo para a unidade curricular de Design de Interação, lecionada pela professora Carla Nave, na NOVA FCSH.

Imagens e fontes

As ilustrações foram geradas com IA (OpenAI), com direção visual de Carla Nave. O logótipo e a direção visual foram desenvolvidos para este projeto. Os conteúdos sobre direitos, história e regras incluem ligações para as fontes.

Origem do compromisso: Tradução e adaptação do bloco The Civic Promise, no rodapé da versão inglesa anterior do próprio projeto. Essa página não indica autor ou fonte externa.

Versão inglesa anterior do projeto: https://civism-education-web-qizza.boli.host/
